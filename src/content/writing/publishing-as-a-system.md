Simon Willison’s site is a compelling example of publication as an operating system for curiosity. The value is not a single grand essay; it is the accumulated context created by notes, links, projects, and longer explanations.

The lesson I take from it is structural: make the smallest useful unit easy to publish, preserve stable URLs, and let the archive become more valuable over time.
